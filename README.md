# Website ـی کۆرسی زیندەزانی ١٢

## ناوەڕۆک
- `index.html`، `styles.css`، `app.js`: وێبسایتەکە.
- `data/lessons.json`: JSON ـی ٤٠ وانەی ئێستا.
- پەخشکردنی ڤیدیۆ بە Bunny Stream iframe.
- گەڕان، فلتەری بەشەکان، ڕووکارە تاریک/ڕوون، و هەڵگرتنی وانە تەواوکراوەکان لە localStorage.
- زیادکردنی JSON ـی نوێ لە دوگمەی «زیادکردنی JSON».

## چۆن لەسەر کۆمپیوتەر تاقی بکەیتەوە
لە ناو ئەم بوخچەیەدا فەرمانەکە جێبەجێ بکە:
```bash
python -m http.server 8000
```
پاشان لە وێبگەڕدا بکەرەوە:
`http://localhost:8000`

تێبینی: فایلەکە بە دبل‌کلیک کردن مەکەرەوە؛ پێویستە لە ڕێگەی web server ـەوە بکرێتەوە، چونکە JSON بە fetch دەخوێندرێتەوە.

## زیادکردنی داتای نوێ
لە سەرەوە «زیادکردنی JSON» هەڵبژێرە. فۆرماتە پشتگیریکراوەکان:
- `{ "details": [ ... ] }`
- `{ "lessons": [ ... ] }`
- یان ڕاستەوخۆ array ـێک لە وانەکان.

هەر وانەیەک باشترە `id`، `title`، `chapter` و `link` ـی هەبێت. ئەگەر `id` دووبارە بێت، وانەکە نوێ دەکرێتەوە؛ ئەگەر نوێ بێت، زیاد دەکرێت.

## گرنگ
زیادکردنی JSON لە ناو وێبسایتەکەدا لە هەمان وێبگەڕدا کار دەکات، بەڵام بۆ هەمیشە نانێردرێتە سێرڤەر. بۆ ئەوەی هەموو بەکارهێنەران داتای نوێ ببینن، دەبێت فایلەکە لە `data/lessons.json` بگۆڕدرێت و دووبارە deploy بکرێت یان backend/API بۆ زیادکردنی داتا زیاد بکرێت.
